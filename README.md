Um projeto simples proposto pelo curso da Hashtag- Jornada Python- para o entendimento do processo de automação de tarefas com bots.

O objetivo é realizar uma tarefa repetitiva, cadastrar itens em uma plataforma de vendas, de forma prática e inteligente.
A base do sistema serve para uso em diversos outros cenários e serviu como ótimo aprendizado de automação em Java. 
A biblioteca utilizada é o Pyautogui para automação do mouse e teclado, com auxílio do pandas para leitura do banco de dados.
